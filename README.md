# LemonsWeapon

Basis-Webseite (statisches HTML/CSS/JS).

## Struktur

- `index.html` – Seitenstruktur (Header, Hero, About, Leistungen, Kontakt, Footer)
- `css/style.css` – Styling, responsive
- `js/script.js` – Mobile-Navigation, Formular-Handling
- `assets/img/` – Bilder

## Lokal öffnen

Einfach `index.html` im Browser öffnen, oder mit einem lokalen Server:

```bash
npx serve .
```
